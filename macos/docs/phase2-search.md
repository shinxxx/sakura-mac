# 阶段 2 第 32 步：查找与替换

**结论**：「検索」菜单里加了原版的「検索...」「次を検索」「前を検索」「置換...」「検索マークの切替え」「検索開始位置へ戻る」「指定行へジャンプ...」。查找、置换、跳转的处理全部用原版的代码（`CSearchAgent`、`CBregexp`、`CViewCommander_Search.cpp` 的逻辑），正则表达式也是原版用的 bregonig + Onigmo，所以找到的位置、置换的结果、「すべて置換」的个数与 Windows 版一致。完成标志（结果与 Windows 版一致）由核心库测试按原版的处理逐项确认，界面测试走一遍查找、全部替换、跳转的实际操作。

## 与原版的对应

| 原版（Windows） | Mac 版 |
| --- | --- |
| 検索ダイアログ（IDD_FIND，非模态，一个窗口一个） | 相同。控件的位置按原版的对话框单位换算 |
| 初始的查找文字：选择的文字（到第一个换行），没有选择时光标位置的单词（「カーソル位置の文字列をデフォルトの検索文字列にする」），再没有时用历史 | 相同 |
| 単語単位 / 英大文字と小文字を区別 / 正規表現（打勾时「単語単位」变灰），旁边显示正则库的版本 | 相同 |
| 見つからないときにメッセージを表示 / 検索ダイアログを自動的に閉じる / 先頭（末尾）から再検索する | 相同，设置存在 sakura.ini |
| 下検索・上検索：找到的文字选中，光标在开头；长度 0 的匹配下一次前进一个字 | 相同 |
| 找不到时「前方(↓) に文字列 '…' が１つも見つかりません。」（设置关掉时蜂鸣） | 相同 |
| 置換ダイアログ（IDD_REPLACE）：置換対象（選択文字・選択始点挿入・選択終点追加・行削除）、範囲（選択範囲・ファイル全体）、クリップボードから貼り付ける、「すべて置換」は置換の繰返し | 相同。多行选择时打开默认「選択範囲」，这时上検索・下検索・置換变灰 |
| 置換：换了以后找下一个，到最后时「最後まで置換しました。」 | 相同 |
| すべて置換：撤销一次全部还原，之后「n箇所を置換しました。」 | 相同 |
| 正则表达式的置换（`$1`、`$&` 等），剪贴板的文字原样插入（不当正则） | 相同 |
| 查找文字的颜色（类型别设置「検索文字列」〜「検索文字列5」，多个单词时每个单词一种颜色） | 相同 |
| 検索マークの切替え：选择中把选择的文字设为查找文字（不用正则、单词单位），没有选择时不显示颜色 | 相同 |
| 検索開始位置へ戻る：回到打开查找、置换对话框时的光标位置（没有时蜂鸣） | 相同 |
| 指定行へジャンプ（IDD_JUMP，模态）：折り返し単位 / 改行単位、PL/SQL コンパイルエラー行 | 相同（Mac 版用表单）。上次的行号保留 |
| 查找、置换的历史（sakura.ini 的 [Keys]），「次を検索」接着别的窗口的查找文字（「次・前検索で他のビューの検索条件を引き継ぐ」） | 相同 |

## 和原版不同、或者现在还没有的

- **快捷键**：⌘F 検索、⌘G 次を検索、⇧⌘G 前を検索、⌘R 置換、⌘J 指定行へジャンプ（第 34 步起按原版的按键分配表，F3／⇧F3 也能用；第 32 步时是 ⌥⌘F、⌘L）。见[菜单与快捷键](phase2-menu-keys.md)。
- **对话框的访问键**：Mac 没有「(&N)」这样的访问键，标签去掉了这部分。
- **查找、置换对话框总在编辑窗口的上面**（浮动面板），App 不是活动的时候隐藏。原版是编辑窗口的从属窗口，效果相同。
- **「該当行マーク」「ヘルプ」按钮**变灰：书签（ブックマーク）和帮助在后面的步骤移植（帮助：第 49 步，[phase3-help.md](phase3-help.md)）。
- **PL/SQL 的块列表**是空的：需要大纲解析（アウトライン解析），在后面的步骤移植。行号的计算本身已经移植。
- **状态栏的消息**（「▼先頭から再検索しました」「▽見つかりませんでした」）：Mac 版还没有状态栏，现在不显示（状态栏在后面的步骤做）。
- **矩形选择中的查找、置换**：从光标位置开始，矩形选择取消；「すべて置換」的「選択範囲」只对普通选择有效（原版矩形选择时按矩形范围置换），在后面的步骤补上。
- **置换中的进度对话框**（「置換中」和取消按钮）：现在没有。大文件的全部替换也在一瞬间完成，以后需要时再加。
- **剪贴板的行模式、矩形形式**在置换时当作普通文字。
- **选择状态的锁定**（F_SELECTLOCK 后的查找扩展选择）：选择锁定在后面的步骤移植。
- **查找文字的粗体、下划线**（类型别设置的「太字」「下線」）：第 33 步与语法颜色一起做了（见[语法高亮](phase2-syntax-color.md)）。
- 跳转历史（移動履歴）、インクリメンタルサーチ、Grep、比較：在后面的步骤移植。
