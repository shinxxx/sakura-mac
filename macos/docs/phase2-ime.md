# 阶段 2 第 25 步：输入法原型

**结论**：新建了自绘文本视图 `EditorTextView`（`macos/app/Sources/EditorTextView.swift`）。它用 Core Text 逐行画文字，不用 NSTextView，并实现了 macOS 的输入法接口 `NSTextInputClient`。编辑窗口已经换成这个视图，可以用日文、中文输入法输入，也能换行、删除、移动光标、撤销。按输入法调用顺序写的 12 个自动测试全部通过。**输入法实际好不好用，需要你在 Mac 上试**（见下面的“请你确认”）。

## 为什么先做这个

计划里输入法是风险最高的一项：Sakura 的编辑画面是自己画的（原版 `CEditView` 用 GDI 逐字绘制），Mac 版也要自己画，才能做到与原版相同的显示（行号、各种记号、按列选择、行间距等）。自己画的视图要自己告诉输入法“文字在哪里、未确定文字放在哪里”。如果这一步接不好，后面的绘制方案就要改。所以在移植编辑画面（第 27～30 步）之前，先用一个简单的视图确认这件事。

## 做法

| 输入法的要求 | 这个视图的做法 |
| --- | --- |
| 显示未确定文字（`setMarkedText`） | 不写进文档，只在画面上插在光标处显示。下划线按输入法给的文节分开画，正在转换的文节用粗线 |
| 确定（`insertText`、`unmarkText`） | 这时才写进文档，所以输入中的变化不进撤销记录：一次撤销回到输入前。与原版相同（Windows 上也是确定时才收到文字） |
| 候选窗口的位置（`firstRect`） | 用 Core Text 算出文字的位置，换成屏幕坐标。范围跨行时只回答第一行的部分 |
| 点 → 文字位置（`characterIndex`） | 同样用 Core Text 换算，与 `firstRect` 一致 |
| 重新转换（`replacementRange`） | 把文档里指定的一段换成未确定文字，确定时再写回 |
| 方向键、Backspace 等（`doCommand`） | 换行、Tab、删除、上下左右、行首行尾、文档首尾。补充平面字符（例如表情符号）不会被拆开 |

输入法用的位置是“文档全文里插入了未确定文字”的 UTF-16 下标，视图负责和文档的逻辑位置（行、列）互相换算。

## 现在还没有的

这是原型，编辑画面的其余部分在后面的步骤移植原版：

- 选择范围、复制粘贴、自动换行、语法颜色、各种记号（第 27～30 步）
- 保存（「上書き保存」等在菜单里还没有；关窗口时不会询问是否保存，修改不会写回文件）
- 字体、颜色按类型别设置（现在固定用系统的等宽字体）
- 竖排、行间距等

## 请你确认（需要在 Mac 上）

准备：按 `macos/README.md` 构建并运行（Cmd+R）。启动后有一个空的编辑窗口。

1. **日文**（系统自带的「日本語 - ローマ字入力」）
   - 输入 `nihongo`：「にほんご」带下划线显示在光标处，后面的文字往右让开，`[EOF]` 也跟着移动。
   - 按空格转换：候选窗口出现在文字的正下方，没有跑到屏幕角落或窗口外。
   - 输入较长的句子（例如 `kyouhaiitenkidesu`）再转换：文节分开画下划线，正在转换的文节是粗线；用左右方向键换文节时粗线跟着移动。
   - 按回车确定：文字变成普通文字，标题出现「(更新)」。
   - Cmd+Z：一次就回到输入前。
   - 在第 2 行以后、行的中间输入，候选窗口的位置也正确。
2. **中文**（系统自带的「简体拼音」）
   - 输入 `zhongwen`：拼音显示在光标处，候选窗口在正下方。
   - 选择候选（数字键或空格）后，汉字写进文档。
   - 输入中按 Esc 取消：文档不变。
3. **其他**
   - 输入中用鼠标点别的位置：未确定文字照原样确定，光标移到点的位置。
   - 窗口滚动后（输入很多行再往下滚）再输入，候选窗口位置仍然正确。
   - 「ファイル > 開く…」打开一个已有文件，在里面输入：文件本身不会被修改（还不能保存）。

## 测试

`macos/app/Tests/EditorTextViewTests.swift` 的 12 个测试（CI 在 macOS 上运行），按输入法调用的顺序直接调用 `NSTextInputClient` 的方法：

- 未确定文字不进文档，确定后进文档；一次撤销回到输入前
- 在多行文字的中间输入，下标换算正确
- `unmarkText` 照原样确定；未确定文字删光就是取消
- 文节（`NSMarkedClauseSegment`）分开
- 重新转换：文档里的一段换成未确定文字，确定后写回
- 确定时带替换范围
- 候选窗口位置：在窗口里、高度是一行、越往后越靠右、下一行更低；全角比半角宽；跨行时只回答第一行
- 点 → 文字位置与 `firstRect` 对得上
- 键盘命令：补充平面字符一次删除、换行、上移、行尾、删除换行符、撤销

桥接层的 6 个测试照旧；核心库的启动改成测试进程里只做一次（`TestCore.swift`）。
